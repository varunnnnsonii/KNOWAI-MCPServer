## 🧭 Key decisions (the "why" at a glance)

| Decision | Rationale | When |
|---|---|---|
| **Modular monolith (NestJS)**, not microservices | One deployable, clear module boundaries; split later only if a seam demands it | Jan 2024 |
| **TypeORM** (not Prisma) | Team choice; expand/contract migrations; all infra + SETUP-GUIDE migrated to it | Jan 2024 |
| **REST everywhere** (no GraphQL) | Simpler one-protocol surface for every frontend + webhooks | Jan 2024 |
| **Dynamic DB-backed RBAC** (not a TS enum) | Scales to many roles; per-module JSON permissions; admin-configurable | Jan 2024 |
| **Permission snapshot embedded in JWT** | Re-resolved on refresh (≤15m staleness); no per-request DB hit (one fast Redis revocation check only) | Jan 2024 |
| **Instant revocation via Redis (not `express-session`)** | Per-user nbf epoch + refresh kill → cut access immediately; keeps Bearer JWT (no cookie/CSRF/SSR rework) | Feb 2024 |
| **Multi-tenancy via `tenant_id` + row-level scope subscriber** | Cheap, single-DB isolation; defense-in-depth against IDOR without per-tenant schemas | Jan 2024 |
| **Tenant resolved from JWT, never from the request body** | The client can never assert a tenant it doesn't own | Jan 2024 |
| **Shipment lifecycle is an explicit state machine** | One authoritative source of legal transitions; illegal jumps rejected and audited | Apr 2024 |
| **Auto-assignment is a pure, testable scorer** | Deterministic dispatch decisions; humans can always override | May 2024 |
| **Tracking ping ingest is write-cheap + idempotent** | Devices retry; out-of-order/stale pings are dropped, not errored | Jun 2024 |
| **ETA from a local model, not a maps call per ping** | Cost + latency; provider call reserved for route planning | Jun 2024 |
| **Heavy work goes to BullMQ workers** (routing, notifications, reports, webhooks) | Decouple slow/external work from the request path; retries survive provider blips | 2024 |
| **External services behind ports** (storage/maps/sms/email/push/payment) | Swap providers without touching domain modules; console dev-fallback when creds unset | 2024 |
| **Webhooks are signed (HMAC) + at-least-once with backoff** | Subscribers verify authenticity; delivery is durable and observable | Nov 2024 |
| **Payments are idempotency-keyed** | Retries never double-charge; provider webhook reconciles truth | Sep 2024 |
| **Frontend = server-default + feature-based + Tailwind/shadcn** | Server Components default; Server Actions for mutations only; shared `@aerolith/ui`; standard for all Next apps | May 2025 |
| **Resilient fetch layer (`ApiResult<T>`, reads never throw)** | Only the fetch seam try/catches; pages check `success` — no server-page crashes | May 2025 |
| **Read replica for reporting** | Isolate heavy analytical reads from the operational write path | 2025 |
| **Audit log is hash-chained, append-only** | Tamper-evidence; deletes/edits are detectable | 2025 |
| **OpenSearch (search/facets) deferred** | DB filters/`ILIKE` are enough for current volumes; revisit later | 2025 |
| One develop VPS + one production VPS (+ staging) | Per project scope; promote `develop`→staging→`main`→prod | 2024 |
